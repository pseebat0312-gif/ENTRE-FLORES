# ENTRE FLORES 🌿
### An Interactive Floral Atelier

*A little garden on the internet, where flowers become something personal.*

**ENTRE FLORES** is an independent creative web project inspired by botanical gardens, vintage floral studios, and the romantic atmosphere of Madrid. It combines editorial aesthetics, interactive storytelling, and playful bouquet customization.

Visitors can explore a living garden, discover the stories behind different flowers, and create their own arrangements.

## The Experience

### 01 — A Garden Through the Seasons
Explore a botanical garden that changes with spring, summer, autumn, and winter, with interactive flowers and atmospheric movement.

### 02 — The Botanical Collection
Select flowers to reveal botanical cards featuring names, meanings, seasonal details, and suggested pairings.

### 03 — Create Your Bouquet
- Choose flowers and foliage.
- Arrange and adjust individual stems.
- Explore ceramic vases, glass vessels, and paper wrapping.
- See estimated prices update as you create.
- Undo and redo changes.
- Save arrangements locally and export PNG images.

### 04 — An Editorial Floral World
A visual experience inspired by botanical photography, warm paper textures, vintage typography, and contemporary floral art direction.

## Design Direction

**Botanical Romanticism × Editorial Design × Interactive Web Experiences**

The visual identity explores warm ivory, terracotta, deep olive green, and burgundy, with restrained motion and natural botanical textures.

**Typography**
- Fleur De Leah — expressive brand lettering
- Pinyon Script — decorative editorial accents
- EB Garamond — reading typography

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- SVG and Canvas-based visual effects
- Responsive layouts and touch interactions
- Browser-based local storage

The website is a standalone static project without a required backend or database.

## Run Locally

```bash
git clone https://github.com/YOUR-USERNAME/entre-flores.git
cd entre-flores
python -m http.server 8000
```

Visit http://localhost:8000. On Windows, `INICIAR_WINDOWS.bat` can also start the local server if Python 3 is installed.

## Deployment

Deploy using Cloudflare Pages or GitHub Pages. For Cloudflare Pages, connect the repository and publish the static files from the directory containing `index.html`; no compilation is required.

## Project Notes

ENTRE FLORES is an independent **conceptual floral atelier**, created as a creative web design and interactive development project. The catalog, prices, and order interface are demonstrations; no real purchases or payments are processed. Saved bouquets remain in the visitor's browser.
